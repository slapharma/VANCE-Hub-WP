# VANCE Health Hub screenshot index

Static site: full size desktop and phone screenshots and scroll videos of vancehealthhub.co.uk, captured 5 October 2026.
Open `index.html` (served by GitHub Pages from this branch). The My Dashboard views use a test account with fictional demo content.

- `shots/` full size PNGs, `desktop/` and `mobile/` then group
- `thumbs/` grid thumbnails
- `videos/` scroll-through MP4s and poster frames

This branch has no shared history with `main` on purpose, so it does not affect the theme or its deploy.
